# 💬 AI Chat Application (Full Stack)

A modern full-stack AI chat application inspired by ChatGPT.  
Built with **Next.js**, **React Query**, **Tailwind CSS**, **shadcn/ui**, and a custom **Node + Express backend**.  
Supports text messages, image uploads, chat history, and live sessions.

---

## 🚀 Features

- 🧠 AI-style chat interface (ChatGPT-like UI)
- 💬 Text messaging
- 🖼️ Image upload support
- ⌛ Typing indicator animation
- 🗂️ Chat history sidebar (multiple sessions)
- ⚡ Optimistic UI updates with React Query
- 🎨 Modern UI using Tailwind + shadcn/ui
- 🔄 Bun for fast local development
- ☁️ Production-ready deployment (Node on Render)
